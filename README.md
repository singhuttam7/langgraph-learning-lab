# LangGraph Learning Lab

A hands-on repository for learning and building applications with LangGraph and the LangChain ecosystem.

This repository contains practical implementations of LangGraph concepts, workflow patterns, tool calling, RAG, human-in-the-loop systems, and agentic AI applications.

## 🚀 What You'll Learn

- LangGraph fundamentals
- State and state management
- Sequential workflows
- Parallel execution
- Reducers
- Conditional routing
- Tool calling
- Web search integration
- Retrieval-Augmented Generation (RAG)
- Human-in-the-loop workflows
- Iterative agent workflows
- LLM-based review and refinement
- Building real-world AI applications
